# Redlam7 Core

Shared foundation for Redlam7 NeoGaming titles.

Common targets:
- Godot 4.x
- portrait/mobile-first layout
- keyboard + touch input
- consistent Redlam7 menus, HUD, pause, game over and scoring
- local high-score persistence
- reusable audio/settings layer

Game projects remain independent so they can be exported and maintained separately.
